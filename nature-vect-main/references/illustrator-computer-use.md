# illustrator-computer-use.md —— 用 computer-use 在 Illustrator 中打开/展示 SVG

本文供**具备 GUI / computer-use 能力**的 agent 使用：把 nature-vect 生成的 SVG 在本机 Adobe Illustrator 中打开并展示给用户。中英双语菜单与快捷键均已给出，兼容 Illustrator 2019–2026。

> 铁律：**只打开，不重画**。SVG 本身就是矢量文件，用 Illustrator “打开”即得到可编辑矢量对象。绝不要试图用画笔/钢笔工具照着图重新画一遍——慢、失真、且违背本 skill 的目的。
>
> 说明：**文字模式（要改字/交付 .ai）不走本文的"手动打开"**——由 `run_nv_replay.ps1` / `run_nv_direct.ps1` 带 `-AutoCanvasFromSvg` 自动启动 AI、新建与图等大的画板并绘制（见 `direct-adobe.md`）。本文主要服务：基础模式"打开看看"、把 `.text.svg` 兜底文件手动打开另存、或电脑上人工补位/复核。

## 文字模式自动建板（优先，取代手动新建画板）

- 文字模式交付 `.ai` 时**不要**用本文的手动「新建画板」流程——用绘制脚本的 `-AutoCanvasFromSvg`：脚本读 Master SVG 的 viewBox → 自动新建宽高=viewBox（1px=1pt）的 RGB 画板并绘制，全程无需用户在 AI 里新建文档（Illustrator 未运行则由脚本 COM 自启，需用户已同意 agent 自动开 AI）。
- 手动「文件→新建→输入宽高」仅作为：脚本自启被安全策略拦截、或用户主动要求手动建板时的兜底。

## 前提检查（不满足就跳过并降级）

- [ ] 本机已安装 Adobe Illustrator（2019–2026 任一版本）
- [ ] 你能看到屏幕、移动鼠标/光标、点击、键盘输入（computer-use 能力）
- [ ] 用户明确要求“在 Illustrator 里打开 / 展示”，或你已征得同意
- [ ] SVG 产物路径已知（来自 convert 的成功输出）

任一项不满足：不要硬来，把 SVG 完整路径告诉用户，让其手动打开。

## 通用步骤（所有 agent 同此）

1. **启动 Illustrator**。通过开始菜单 / Dock / Spotlight / 运行框启动，等待欢迎页或空文档出现（用屏幕截图确认，别猜）。
2. **打开 SVG**：
   - 菜单：`文件 → 打开`（Windows 中文） / `File → Open`（English）
   - 快捷键：`Ctrl+O`（Windows）/ `Cmd+O`（macOS）——能用快捷键就用快捷键，最稳。
3. **在打开对话框中直达路径**（避免在目录树里乱点）：
   - Windows：先按 `Ctrl+L` 让光标落到地址栏，粘贴完整路径，回车。
   - macOS：按 `Cmd+Shift+G`（前往文件夹），粘贴路径，回车。
   - 若对话框不响应快捷键：退回用目录树点选，每步截图确认。
4. **确认导入**：若出现“导入 SVG”设置对话框，保持默认（不做勾选），点“确定/OK”。等待文档加载完（画板出现图形）。
5. **展示与验证**：
   - 按 `Ctrl+0` / `Cmd+0` 缩放到适合窗口。
   - 用“选择工具”（V，工具栏第一个黑色箭头）点一下图形，确认对象被选中（出现蓝色包围框）——这就是“可编辑矢量”。
   - 想更有说服力：打开“图层”面板（`窗口→图层` / `Window→Layers`，快捷键 `F7`），把图层眼睛图标点掉/点回，演示图形可按图层开关。
6. **向用户汇报**：
   - SVG 已打开、矢量对象可选中编辑；
   - 图中文字是**字形路径**（不是文字对象）：可在 AI 里当图形修改；如需改字，用文字工具手动重打即可（MVP 不做自动转换）。

## 中英文菜单对照

| 操作 | 中文（Windows/macOS） | English | 快捷键 |
|---|---|---|---|
| 打开 | 文件 → 打开 | File → Open | `Ctrl+O` / `Cmd+O` |
| 缩放到适合窗口 | 视图 → 适合窗口大小 | View → Fit Artboard in Window | `Ctrl+0` / `Cmd+0` |
| 缩放 | 视图 → 放大/缩小 | View → Zoom In/Out | `Ctrl++ / Ctrl+-`，mac 对应 `Cmd` |
| 选择工具 | 工具栏第一个（黑色箭头） | Selection Tool | `V` |
| 图层面板 | 窗口 → 图层 | Window → Layers | `F7` |
| 重做 | 编辑 → 重做 | Edit → Redo | `Ctrl+Shift+Z` / `Cmd+Shift+Z` |

2019–2026 各版本以上菜单与快捷键基本一致；若某个版本菜单名不同，用快捷键或“帮助→搜索命令”兜底。

## 中途出现的对话框怎么处理

- **“缺少字体”**：MVP 输出是字形路径，一般不出现；若出现（例如产物含少量 `text`），点“确定/OK”让 Illustrator 用默认字体替换即可，不是错误。
- **导入设置对话框**：保持默认，直接确定。
- **未保存更改 / 许可证弹窗 / 更新提示**：一律点“取消/稍后/Not Now”，不要点会中断操作的选项。
- **操作系统授权弹窗**（辅助功能/屏幕录制权限）：如实告诉用户需要授权，按其指引开启后重试；不要硬绕过。

## 各家 agent 的差异

### Codex（computer-use 插件 / 具备 GUI 的 Codex 形态）

- Codex 通过 computer-use 插件或自带 GUI 工具获得“看屏→点击/输入”循环。本手册的通用步骤即为其执行序列。
- 实操建议：每执行 1 步先截图、确认界面再点下一步；打开对话框时优先 `Ctrl+L` 粘贴路径。
- 具体调用语法（插件名、是否要额外安装）以你所用 Codex computer-use 插件的当前文档为准。

### 豆包（桌面端）

- 若豆包客户端提供 computer-use / 屏幕操作能力：直接按通用步骤执行。
- 若豆包没有 GUI 控制能力（或未开启）：**不要假装操作**。向用户说明“当前客户端不能自动操作 Illustrator”，给出 SVG 完整路径让用户自己 `文件→打开`，或另用支持 computer-use 的 agent（如 Codex）重跑。

### 其它 agent（Trae / Claude 桌面 / 自定义）

- 原则相同：agent 有 computer-use 就用通用步骤；没有就降级为“给路径手动打开”。
- 唯一区别是 GUI 操作的“开 关”（谁触发、是否需授权），与本 skill 无关。

## 失败兜底清单

| 现象 | 处理 |
|---|---|
| Illustrator 未安装 | 停：给路径让用户装好后再开，或用户手动用其它软件打开 |
| 打不开 / 一直转圈 | 截图确认是否在等授权或弹窗；等 10 秒再截图一次；仍不行就停 |
| 找不到菜单或按钮 | 用快捷键；再不行用“帮助→搜索”（中英都行） |
| computer-use 环境不稳（点错位置） | 立即截图回读，撤回到上一步重来；连续 2 次失败就停手降级 |
| 任何不确定 | 停止自动化，把 SVG 路径交给用户手动打开 |

## 安全与边界

- 只在用户明确同意时操作本机 GUI；出现敏感/危险弹窗（付款、删除、联网授权）一律停手并询问用户。
- 你只做“打开 + 展示 + 验证可选中”，不重新绘制、不主动修改文档内容、不导出/保存覆盖用户的 SVG（除非用户要求）。
